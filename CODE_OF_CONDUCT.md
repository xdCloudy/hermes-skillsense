# Code of Conduct

## Our standard

Participants should be professional, constructive and respectful. Focus criticism on code, evidence and ideas rather than personal characteristics.

Harassment, discrimination, threats, doxxing, unsolicited sexual content, deliberate disruption, and publication of private user data are not tolerated.

## Scope

This applies to repository discussions, issues, pull requests, reviews and project community spaces.

## Enforcement

Maintainers may request edits, remove abusive content, restrict participation or ban accounts, proportionate to the behaviour involved.

Report concerns privately to a repository maintainer using GitHub's available private contact or reporting features. Avoid putting private details into a public issue.

This code is intended to make technical collaboration safe and productive for contributors and users.
