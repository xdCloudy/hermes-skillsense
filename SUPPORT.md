# Support

SkillSense is a **pre-alpha** Hermes plugin project. There is currently no supported production release.

## Where to ask

- **Questions and ideas:** [GitHub Discussions](https://github.com/xdCloudy/hermes-skillsense/discussions), if enabled, or use a GitHub issue.
- **Bugs and compatibility:** [GitHub Issues](https://github.com/xdCloudy/hermes-skillsense/issues). Include OS, Python version, Hermes version, reproduction, and sanitised logs.
- **Security vulnerabilities:** follow [SECURITY.md](SECURITY.md); do not post exploit details or secrets publicly.

## Before filing an issue

Run the scaffold unit tests and the Hermes plugin validator as documented in [docs/DEVELOPMENT.md](docs/DEVELOPMENT.md). Never paste API keys, private skill files, sensitive transcripts, or a full Hermes configuration. The initial skeleton intentionally does not inject routing hints or run Metadata Clean.

## Response expectations

This is a volunteer project; no response time or maintenance SLA is promised. Prioritise reproducible defects and issues affecting correctness, portability or privacy.
