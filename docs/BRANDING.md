# SkillSense Brand Guide

## Identity

- **Project name:** SkillSense
- **Maintainer:** xdCloudy
- **GitHub repository:** `xdCloudy/hermes-skillsense`
- **Tagline:** The right skill. Right on cue.
- **Descriptor:** Local-first, intelligent skill routing for Hermes Agent.
- **Cloud motif:** Represents xdCloudy without duplicating "Cloudy" in the display name.
- **Routing motif:** Branching paths and one clearly selected destination.
- **Status:** Independent community plugin; not officially affiliated with Nous Research.

## Artwork

The approved primary lockup is `assets/skillsense-logo.png`, featuring a cloud, branching route and checkmark with the **SkillSense** wordmark. Use a transparent background and retain breathing room. Do not redraw Hermes' own logo or imply official endorsement.

For small icons, create an **icon-only derivative** rather than shrinking the entire wordmark to unreadable sizes. Optimise both dark- and light-mode legibility before using it as a marketplace icon.

## Copy rules

Say "local-first", "BM25-powered" and "on-demand metadata auditing" only in the context of planned vs implemented status. Never claim a neural model runs per prompt, promise zero false matches, or publish unmeasured speed gains.

Always name the project **SkillSense**, not "Cloudy SkillSense", in user-facing copy. The repository slug retains `hermes-` for discovery.
